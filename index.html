📋 What is wecert?

wecert is a tool that keeps your website's security certificates up to date automatically. If you run a website on Tencent Cloud's Load Balancer (CLB), you know how important it is to have a valid SSL certificate. Your visitors see a message like "Connection not secure" if your certificate expires. wecert fixes this for you, automatically, without you having to do anything.

Think of it as a friendly robot that checks your certificates, renews them when they're about to expire, and puts the new one in place — all while your website stays online. No downtime, no warnings, no headaches.

⚙️ How It Works — For Your Understanding

You don't need to know these details to use wecert. But if you're curious, here's a friendly explanation:

  • Certificate Manager-style: It works similarly to popular tools used by big companies, but it's much simpler to set up.
  • DNS-01 Validation: This is how it proves you own your domain. It uses DNSPod, Tencent Cloud DNS, Cloudflare, or Amazon Route 53 to do this automatically.
  • ARI (RFC 9773) Aware: A recent improvement that tells wecert exactly when to renew — not too early, not too late.
  • Zero-Downtime Rebind: When a new certificate is obtained, wecert seamlessly updates your CLB without anyone noticing.
  • One Binary, One SQLite File: Everything is in the single file you downloaded. Your settings and data are saved in a tiny database file right next to it.

📖 Need More Help?

Here are some quick answers to common questions:

What if I don't have a Tencent Cloud CLB?

wecert is specifically designed for Tencent Cloud CLB. If your website doesn't use that, this tool may not be the right one for you. But if you're using it, wecert is a perfect fit.

I use Cloudflare. Is that okay?

Yes! wecert supports Cloudflare, DNSPod, Tencent Cloud DNS, and Amazon Route 53 for the DNS challenge. You'll enter your API credentials during setup.

Do I need to know programming?

No. wecert is designed for everyone. If you can follow instructions on a screen, you can use it.

Does this cost money?

wecert itself is free and open-source. The SSL certificates it uses (from Let's Encrypt) are also free. The only costs are your existing Tencent Cloud services and DNS provider.
